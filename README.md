# Portfolio Website

A **clean, modern portfolio** built with **React** and **Tailwind CSS**. This site features:

---

- Hero (with name, tagline, and buttons)
- About Me
- Skills
- Projects
- Contact
- Footer

---

## ✅ Tech Stack Used

- React (Create React App)
- Tailwind CSS
- Framer Motion (for smooth animations)
- React Icons
- Responsive Design with Flexbox/Grid

## How to Run

1. Install dependencies:

   ```sh
   npm install
   ```

2. Start the development server:

   ```sh
   npm start
   ```

3. Build for production:

   ```sh
   npm run build
   ```
